Customer Account Takeover Detection

A supervised machine learning system that classifies login attempts as Normal or Potentially Compromised.

Predict an Account View Dashboard
Supervised Learning

Trained on the Login Data Set for Risk-Based Authentication, using labeled login attempts with a known Is Account Takeover target.

3 ML Models Compared

Logistic Regression, Decision Tree and Random Forest were trained and evaluated using accuracy, precision, recall, F1-score and ROC-AUC.

Explainable Output

Every prediction includes a probability score, and the dashboard visualizes the confusion matrix and feature importances of the final model.

How it works

  1. Data loading — login attempts are read from a CSV file.
  2. Cleaning & preprocessing — missing values are imputed, numeric features are scaled, categorical features are one-hot encoded.
  3. Feature engineering — the login timestamp is converted into login_hour and login_day_of_week.
  4. Model training — three classifiers are trained with class balancing to handle the rare ATO class.
  5. Evaluation — models are compared and the best one (by F1-score) is saved with joblib.
  6. Web deployment — a Flask app loads the saved model and serves predictions through a form.
About the dataset

Login Data Set for Risk-Based Authentication — a large-scale, publicly available research dataset of realistic single-sign-on login attempts with a documented account-takeover ground-truth label.

Note: the dataset is synthetic and is intended for research and educational use only.
